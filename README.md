# Smart Shop Management System

## Project Introduction
Smart Shop Management System is a Java-based Data Structures and Algorithms (DSA) project designed to manage basic shop operations, including products, inventory and sales.

## Project Objectives
- Manage product records.
- Maintain inventory information.
- Record and manage sales.
- Apply DSA concepts through practical implementation.

## Technologies Used
- Java
- Visual Studio Code
- Git and GitHub

## DSA Concepts Used
- Fixed-size Arrays
- Array Traversal
- Manual Insertion and Deletion
- Searching and Updating
- Linear Search
- Bubble Sort

## Project Structure
1. Main.java – Main program.
2. Product.java – Product class.
3. Sale.java – Sale class.
4. ProductManager.java – Product management.
5. InventoryManager.java – Inventory management.
6. SalesManager.java – Sales management.

## Project Status
Milestone 2 – Working Prototype (Development in Progress).

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Compile the Java files:

   `javac *.java`

4. Run the program:

   `java Main`

## Project Requirements
This project uses fixed-size arrays and manual DSA operations without using ArrayList, LinkedList or built-in sorting methods.
